# Multi-Tool Autonomous AI Agent

A Python agent using LangChain and Google Gemini.

## Tools
- DuckDuckGo web search
- Safe arithmetic calculator
- Restricted local text-file reader

## Interfaces
- `main.py`: console interface
- `streamlit_app.py`: browser interface

## Security
Store the Gemini API key in Colab Secrets or a local `.env` file. Never commit a real API key.
